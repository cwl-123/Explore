# 创业板 ETF 三季报体检（2026-10-30）

创业板指（399006）与创业板 ETF（159915）的成分股 Q3 财报、估值、历史类比与 3% 仓位操作规则。

## 重新生成

```bash
cd cyb-2026-10
../hs300-strategy-lab/.venv/bin/python build.py
cd ..
python3 build_site.py   # 注入站点导航 + 更新门户
```

`build.py` 读取 `data/`，生成 `index.html`；`template.html` 是页面模板，`template.html` 本身不登记到门户。

## 数据口径

- 指数：国证指数 399006 日线，2026-10-30 收盘 2,413.63；ETF 159915 收盘 2.435。
- 持仓：159915 2026 Q3 披露 76 只，合计占净值 87.5%；权重为占净值比例，未归一化。
- 财务：2026 三季报 / 半年报 / 一季报、2025 三季报 / 半年报、2025 年报、2024 年报；Q2 单季 = 上半年 − 一季度，Q3 单季 = 前三季 − 上半年；Q3 环比 = Q3 单季 / Q2 单季 − 1；单季毛利率由累计毛利率还原。TTM = 2025 年报 + 2026 前三季 − 2025 前三季。76/76 已披露。
- 估值：乐咕乐股 399006 月度 PE-TTM / PB（2010-06 起）；10/30 估值按指数当日涨跌从 10/29 折算，为估算值。
- 个股行情：腾讯行情 2026-10-30 收盘；PE 为 TTM。
- 历史条件收益：2010-06 至 2026-10 月度收盘，样本重叠，仅供赔率参考。

## 主要文件

- `build.py`：指标计算 + 页面生成
- `template.html`：样式、ECharts 配置、持仓表交互
- `data/merged.csv`：76 只持仓的行情 / 财务 / 行业合并表
- `data/np2024.csv`：用于“正常化 PE”的 2024 年归母净利润
- `data/q1_2026.csv`：2026 一季报（营收 / 归母净利 / 毛利率），用于计算 Q2、Q3 单季与环比
- `data/cyb_index.csv`、`data/index-basic-pe.csv`、`data/index-basic-pb.csv`：指数与估值序列
- `data/etf_holdings.csv`、`data/quotes.csv`、`data/etf_159915.csv`：持仓与行情

## 部署注意

线上站点（hyset.me/explore）在服务器上拉取仓库后会自行运行 `build_site.py` 生成根 `index.html`。因此提交时**只提交报告目录与数据**，不要把本地生成的根 `index.html` 一起提交；否则服务器本地的门户产物会阻塞下一次 `git pull`。

## 注意

页面是数据研究，不构成投资建议。历史样本只有 16 年、两轮半牛熊，条件统计的样本量较小；ETF 持仓为 Q3 末披露，10 月后实际权重已变化。
